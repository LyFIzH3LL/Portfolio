# Snahashis Sarker Arnob — Portfolio

Personal portfolio of Snahashis Sarker Arnob, software engineer and AI researcher. It presents research in LLM memory, hyperspectral imaging and NLP, industry experience in full-stack development, selected projects, and a contact form.

**Live site:** [soumikportfolio.vercel.app](https://soumikportfolio.vercel.app)

## Features

- Multi-page layout: Home, Research, Experience, Projects, Skills and Contact
- Contact form with server-side validation and spam protection, delivered by email through Resend
- Light and dark themes that follow the visitor's system setting
- Responsive from mobile to desktop, with a collapsible navigation menu on small screens
- Accessible markup: semantic landmarks, skip link, visible keyboard focus and reduced-motion support
- All content kept in a single typed data file, separate from layout
- Downloadable résumé and generated favicons for browsers and iOS

## Tech stack
